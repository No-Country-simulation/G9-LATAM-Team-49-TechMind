# Entrega para el desarrollador de la API Python

Empieza por [INFORME_TECNICO.md](INFORME_TECNICO.md). Allí se describe la arquitectura, el backend Java, el estado observado del modelo, el contrato REST propuesto y los criterios de aceptación.

## Aviso importante

Esta entrega incluye el notebook ejecutado y las fuentes disponibles, pero **no contiene los artefactos entrenados independientes** que el notebook generó en su entorno de ejecución. Antes de terminar la API deben solicitarse a Data todos los modelos, vectorizadores, configuraciones y bases persistentes necesarios para arrancar sin Jupyter o Colab.

El contrato de `/api/v1/analyze` es una propuesta de trabajo. Debe confirmarse con Backend antes de publicarlo como contrato definitivo.
